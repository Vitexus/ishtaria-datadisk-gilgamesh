# Snare trap („oko“)

Primitive rope snare for the hunter quest (Epic Tablet I): forked wooden stake,
running line, standing noose (*oko*), trigger peg and ground peg.

Built in Blender via MCP when Poly Pizza / Sketchfab had no suitable Early Dynastic
animal snare (only modern metal bear traps and unrelated “snare” hits).
