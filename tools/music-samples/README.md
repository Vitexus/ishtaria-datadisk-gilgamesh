# Soundtrack sample sources (CC0)

Mixed under newly synthesized gish-gudi / zurna beds (`tools/compose_music.py`).
Inspired by public descriptions of Sumerian instruments (lute ancestor and reed oboe with circular-breathing drone), not by sampling any commercial recording.

Tracks use a shared Gilgamesh leitmotif, sectioned timelines (verse / rest / answer),
heterophonic lute–zurna lines, and crossfaded ambient loops.
