# Research notes

This folder holds our own notes on the sources of the datadisk (`*.md`): what each source says, how it was used and where it
comes from. **The sources themselves are not part of the repository**: papers, books, saved web pages, photographs, maps and
datasets belong to their authors and publishers, so they are kept out of git (see `.gitignore`).

To work on a part of the disk that was drawn after a source, read its note, fetch the source where the note says
(`tools/fetch_oracc_translations.py` and `tools/fetch_cdli_translations.py` fetch the translations; open-access papers are
linked in the notes) and put it into this folder. The tools that read such files name the path in their first lines.
